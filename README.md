# 💡 Ideas Lab

**Board:** https://zov911.github.io/ideas-lab/

A public backlog of AI agents, marketing-tech tools and B2B calculators I'm planning to build. Each idea is a GitHub issue:

- 👍 **React with a thumbs-up** on the ideas you want. The most-voted get built first and open-sourced.
- 💬 **Comment** with your use case. Real use cases shape the spec.
- ➕ **[Suggest an idea](https://github.com/zov911/ideas-lab/issues/new?template=idea.yml)**.
- 🏗️ **Need one now?** I build custom versions for businesses → [zov911.com](https://zov911.com)

## How ideas move

`💭 Idea` → `📐 Speccing` (problem, users, architecture written up in the issue) → `🔨 Building` → `🚀 Shipped` (its own repo + live demo). Effort: **S** = days, **M** = 1–2 weeks, **L** = several weeks.

The board (`index.html`) reads `ideas.json` and live 👍 counts from the GitHub API.
